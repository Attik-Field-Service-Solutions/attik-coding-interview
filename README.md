# Attik Coding Interview

Next.js + TypeScript + Tailwind starter for the Attik coding interview.

## Setup

```bash
git clone https://github.com/christo9090/attik-coding-interview.git
cd attik-coding-interview
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Instructions

See **[INTERVIEW.md](./INTERVIEW.md)** for the full interview tasks.

Use an AI-based IDE (Cursor, Claude Code, etc.). Tab complete is allowed.
